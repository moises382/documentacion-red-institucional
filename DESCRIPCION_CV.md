# Descripción para CV y portafolio

## Versión breve

Desarrollé una aplicación web en español para documentar infraestructura de red: inventario editable, topología visual, control de inconsistencias, historial de cambios y reportes semanales. Construida con Next.js, React, TypeScript y SQLite.

## Versión con viñetas

- Diseñé e implementé un inventario de equipos, direcciones IP, puertos, VLANs, racks, patch panels, enlaces troncales y dispositivos PoE, con plantillas reutilizables por tipo de equipo.
- Construí un visor de topología basado en los registros, filtros por sede y alertas para direcciones IP o puertos duplicados.
- Implementé una API con validación, persistencia transaccional en SQLite, historial de cambios y reportes semanales descargables.

## Texto para describir el proyecto en GitHub

Aplicación de documentación y seguimiento de red institucional desarrollada como proyecto personal. Permite organizar inventario, visualizar conexiones, registrar pruebas y pendientes, y generar reportes semanales. El repositorio incluye instrucciones para Windows y macOS y datos ficticios de demostración.

## Cómo presentarlo

En tu CV, enlaza [el repositorio público](https://github.com/moises382/documentacion-red-institucional) y menciona que los datos publicados son ficticios. Si muestras la aplicación original de Sites, recuerda que su acceso es privado y otras personas no podrán abrirla sin invitación.
